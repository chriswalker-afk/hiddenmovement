# Shadow Bearings (working title)

A browser-based, bearings-driven hidden-movement game for mathematics learners. One player is a **Hunter** and the other is a hidden **Monster**. The Hunter follows traces left at previously visited locations and uses three-figure bearings to deduce where the Monster might be.

This project is an **original game inspired by the hidden-movement genre**. Its own maps, artwork, terminology and gameplay should be developed independently.

## Intended modes

- **Solo hunt:** one student plays the Hunter against an AI Monster, with progressive difficulty.
- **Pass-and-play:** two students share a device, passing it between roles behind a privacy screen. Each turn's hidden information must not appear to the opposing player.
- **Future option:** two-device multiplayer, after the rules have been tested.

## Core mathematics

Bearings are measured **clockwise from north** and entered in three-figure notation (for example, `070°`, `180°`, `305°`). Players use bearings to travel, interpret precise or approximate directional clues, apply reverse bearings, and intersect possible directions.

This repository is at the **game-design stage**. Rules and difficulty values are initial proposals to be playtested, not final balancing decisions.
